IMAGES — Placeholders à remplacer
==================================

Tous les fichiers de ce dossier sont des PLACEHOLDERS au format SVG (générés
automatiquement). Ils sont élégants mais génériques : remplacez-les par les
vraies photos du client.

Deux possibilités :
  A) Conservez le même nom de fichier (ex. remplacez "realisation-1.svg" par
     votre photo nommée "realisation-1.svg") — rien d'autre à faire.
  B) Utilisez vos propres noms (ex. .jpg / .webp) et mettez à jour le "src"
     correspondant dans les fichiers HTML.

Conseil performance : JPG ou WebP optimisés, < 300 Ko, format paysage.
