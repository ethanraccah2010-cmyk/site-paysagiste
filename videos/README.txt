VIDÉO HERO
==========

Déposez ici la vidéo du hero (vue drone d'une réalisation) sous le nom :

    drone.mp4

Recommandations :
  - Format : MP4 (codec H.264), muet (la lecture est "muted autoplay").
  - Durée : 8 à 20 s en boucle.
  - Poids : compressez fortement (< 4-6 Mo) pour un chargement rapide (LCP).
  - Résolution : 1920x1080 suffit largement.
  - Fournissez aussi une image d'aperçu : images/hero-poster.jpg
    (référencée dans l'attribut "poster" du <video> de index.html).

IMPORTANT
---------
Tant que ce fichier "drone.mp4" est absent, le site reste parfaitement
présentable : c'est l'image "poster" (images/hero-poster.svg) qui s'affiche.
En "prefers-reduced-motion", la vidéo est de toute façon remplacée par l'image.
